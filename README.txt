BIRTHDAY SURPRISE WEBSITE — EASY SETUP

1. Extract birthday_surprise_website.zip.
2. Open the extracted folder in VS Code.
3. Open index.html and edit:
   - Replace "My Favourite Human" with his name or nickname.
   - Edit the letter inside <div id="letter"...> with your own message.
   - Change captions to your memories.
4. Add photos:
   - Put 4 photos in the photos folder.
   - Rename them photo1.jpg, photo2.jpg, photo3.jpg, photo4.jpg.
   - If your files are .png or have different names, change the src filenames in index.html.
5. Add audio:
   - Put your audio file in the audio folder and name it music.mp3.
   - Use audio you have permission to share. Visitors usually need to press play.
6. Preview:
   - Double-click index.html to open it in a browser, or use Live Server in VS Code.

HOW TO TURN IT INTO A LINK:
The website needs to be hosted online before you can send a public link. An easy option is Netlify:
- Visit https://www.netlify.com/ and sign in.
- Use its manual deploy / drag-and-drop publishing option if available.
- Upload the extracted website folder (the folder containing index.html, photos, and audio).
- Netlify will give you a public website URL; copy and send that link.
- Keep the photos and audio folders together with index.html when publishing.

Important: Anyone with the link may be able to view the page and its photos/audio. Avoid adding private information you would not want shared.
